# Support

## Documentation

- **README**: Start with the [README](README.md) for a project overview and quick-start instructions.
- **API Reference**: When running the application, interactive API documentation is available at `/docs` (Swagger UI) and `/redoc` (ReDoc).
- **Infrastructure Guide**: See `infra/` for Docker Compose configuration and deployment examples.
- **Configuration Reference**: Environment variables and their descriptions are documented in `infra/.env.example`.

## GitHub Issues

Use [GitHub Issues](https://github.com/dataforge-ai/dataforge/issues) to:

- Report bugs and unexpected behavior.
- Track feature requests and enhancements.
- Ask questions about usage and configuration.

Before opening a new issue, please:

1. Search existing issues (open and closed) to avoid duplicates.
2. Use the appropriate issue template if one exists.
3. Provide a clear, minimal reproduction for bugs.
4. Include relevant configuration, logs, and environment details.

## Feature Requests

We welcome feature suggestions. To submit one:

1. Open a [GitHub Discussion](https://github.com/dataforge-ai/dataforge/discussions) with the `idea` category.
2. Describe the problem you are trying to solve, not just the solution you have in mind.
3. Explain how this feature would benefit the broader community.

Popular and well-defined feature requests may be promoted to the [roadmap](ROADMAP.md).

## Community Support

- **GitHub Discussions**: The best place for questions, ideas, and community conversation.
- **Stack Overflow**: Tag questions with `dataforge-ai` for community answers.
